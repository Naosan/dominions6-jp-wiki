## このWikiの読み方

各攻略記事では、なるべく次の順で整理します。

1. **仕様** — ゲーム上どう動くか
2. **攻略上の意味** — その仕様が実戦で何を意味するか
3. **使い方** — 何と組み合わせるか
4. **Counter** — 何に弱いか
5. **よくある誤解** — 初見で間違えやすい点

!!! note "バージョンについて"
    Dominions 6 はアップデートで数値・研究レベル・効果が変わることがあります。記事ごとに確認バージョン・確認日を残す方針です。
