# Pretender God

Pretender設計を、Chassisの強さではなく**国家が必要としている役割**から整理します。

## 主な設計思想

- Awake Expander
- Scales
- Bless
- Rainbow / Magic Diversity
- Global caster
- Late-game Supercombatant

## 設計時に見るもの

- 国家のExpansion性能
- Sacredへの依存度
- MageのMagic Path
- 不足しているResistance / Magic Diversity
- 必要なBoosterや高級Ritual
- ScalesによるGold / Resource / Researchへの影響

今後、BlessとScalesを独立ページへ分割します。
