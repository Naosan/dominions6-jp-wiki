# 初心者向けTips

Dominions 6を始めた直後に特に重要な考え方をまとめます。

## 毎ターンMageを雇う

多くの国家ではCommander Pointが研究速度の上限になります。兵士だけでなく、将来のResearchとBattle Magicを作るMageの継続雇用を意識します。

## Battle Replayを見る

負けた戦闘は最良の教材です。

- 最初にどの部隊が崩れたか
- 何のDamageで死んだか
- MageのScriptが予定通り発動したか
- Fatigueが100へ到達していないか
- Morale崩壊か純粋な損害か

を確認します。

## 「強いUnit」より相性を見る

Protection、Defence、MR、Resistance、Weapon Length、Damage Typeなど、相手の防御層に対して適切な攻撃を選ぶことが重要です。
