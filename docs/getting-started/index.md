# 初心者ガイド

Dominions 6 は非常に情報量が多いゲームですが、最初からすべてを覚える必要はありません。

まず次の5点を意識します。

1. Goldで兵士とCommanderを雇う
2. MageをResearchさせる
3. Independent Provinceを占領して領土を増やす
4. Research・Magic Path・Gemを組み合わせる
5. 戦闘Replayを見て「何に負けたか」を確認する

## 最初の目標

最初のゲームでは「最適解」を探すより、次のサイクルを回せれば十分です。

> 拡張 → Research → 新しい魔法を試す → Battle Replayを見る → 編成を変える
