# 戦闘の基礎

Dominions 6 の戦闘は「兵数」だけでは決まりません。

特に重要なのは以下です。

- Attack Skill
- Defence Skill
- Protection
- Strength
- Weapon Damage
- Weapon Length
- Morale
- Fatigue
- Magic Resistance
- Fire / Cold / Shock / Poison Resistance

まずは [両手武器・片手武器・盾](weapons-and-shields.md) から読むと、Unitの見方が掴みやすくなります。
