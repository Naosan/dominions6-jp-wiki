# Dominions 5からDominions 6への主な変更点

Dominions 5の攻略情報を読む際に注意すべき、Dominions 6の主要変更を整理します。

## 重要項目

- Glamour Pathの追加
- Magic Path / Spellの再配置
- Battlefield terrain / obstacle
- MountとRiderの分離
- Plane / CaveなどのMap拡張
- Legendary Spell
- Nation / Unit / Pretenderの再調整

!!! warning
    旧作のSpell Research LevelやUnit数値をDom6へそのまま適用しないでください。
