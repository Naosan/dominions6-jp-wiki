# 特殊能力

UnitやCommanderが持つ特殊能力を、仕様と攻略上の意味に分けて整理するページです。

## 優先して整備する能力

- Sacred
- Stealthy
- Glamour
- Ethereal
- Awe
- Fear
- Berserker
- Regeneration
- Recuperation
- Reinvigoration
- Formation Fighter
- Bodyguard
- Assassin
- Inspirational / Taskmaster
- Undead / Demon / Magic Being / Mindless / Lifeless
- Darkvision
- Fire / Cold / Shock / Poison Resistance
- Invulnerability
- Damage Reversal / Luck系能力

各能力について、**何を防ぐか・何を防がないか・代表的なCounter**を併記します。
