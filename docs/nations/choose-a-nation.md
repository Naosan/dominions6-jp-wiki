# 国家選択ガイド

最初の国家は「最強」より、**自分が何を学びたいか、どの操作量を許容できるか**で選ぶと理解が進みます。

## 最初に決める七つの質問

### 1. 一般兵を中心に戦いたいか

Yesなら、装備が明快で、Recruit-anywhere兵が主力になる国家が扱いやすいです。

確認するもの:

- Shield / Protection
- Weapon Damage
- Resource cost
- Formation Fighter
- MageによるArmy Buff

### 2. SacredとBlessを中心にしたいか

Sacred国家ではPretender設計が軍事力に直結します。

確認するもの:

- Cap-onlyかRecruit-anywhereか
- SacredのGold / Resource cost
- Priest供給
- Holy Point / Recruit limit
- Incarnate Bless依存
- Anti-Sacred兵への耐性
- 中盤以降の補充速度

Light Bless、Heavy Bless、Scalesとの交換、Incarnate Blessの登場時期は[Pretender設計サンプル](../pretender/samples.md)で比較できます。

Heavy Sacredの具体例は[EA Abysia](ea/abysia.md)、Giant Sacredと通常巨人を混ぜる例は[EA Niefelheim](ea/niefelheim.md)を参照してください。

### 3. GiantやMonsterを使いたいか

少数精鋭は一体ごとの性能が高い一方、包囲、Fatigue、MR攻撃、Armor Negating、Afflictionへの弱点があります。

確認するもの:

- HPとSize
- 一Squareあたりの攻撃回数
- DefenceとHarassment
- Encumbrance
- Magic Resistance
- Regeneration access
- Shock・Poison・AN対策
- Chaffを用意できるか
- 一体を失った補充Turn

Giantの基準記事は[EA Niefelheim](ea/niefelheim.md)です。

### 4. Mage中心の戦闘をしたいか

Mage国家では、Pathの高さだけでなく**Recruit-anywhere Mageの価格とCommander Point**が重要です。

学びやすいテーマ:

- Army Buff
- Evocation
- Communion
- Skeleton spam
- Foul Vapors
- Battlefield Enchantment
- Magic Phase movement

Communionを学ぶ場合は、Master / Slave数、Fatigue、安全なScriptまで扱う[MA Pythium](ma/pythium.md)を基準にします。

### 5. Bloodを管理したいか

Bloodは独立した経済圏です。強い一方、Blood Hunter、Unrest、Population、Slave輸送を毎Turn管理します。

最初の一戦でゲーム全体を学びたい場合、Blood依存が低い国家の方が操作は軽くなります。

Bloodを補助Engineとして使う例はEA NiefelheimとEA Abysiaです。Bloodを国家の中心にする具体例は[EA Mictlan](ea/mictlan.md)です。

Hunter選定、Population、Unrest、Patrol、Slave輸送、Sabbath、Blood Sacrificeの共通手順は[Blood Economy・Blood Hunt・Blood Sacrifice](../magic/blood-economy.md)を参照してください。

### 6. Stealth・Raid・機動戦をしたいか

正面決戦よりMap全体を動かしたいなら、次を重視します。

- Stealthy / Glamour
- Flying
- Sailing
- 高Map Move
- Cheap commander
- Magic Phase movement
- Province Defenceを抜く小部隊

Glamour・Stealth・Sailingを国家Engineとして学ぶ基準は[EA Vanheim](ea/vanheim.md)、共通仕様は[Stealth・Glamour・特殊作戦](../systems/stealth-glamour.md)です。Flying集中とStormは[MA Caelum](ma/caelum.md)と[Flying・Storm・Air機動戦](../systems/flying-storm.md)を参照してください。

### 7. Underwater国家を選ぶか

Underwater国家は地上侵攻、Amphibious性能、装備制限、海陸両方のFort生産を学ぶ必要があります。独自性は高いですが、最初のゲームでは陸上国家より判断項目が増えます。

海中ExpansionからLandfallまでを一続きで学ぶ基準は[MA Atlantis](ma/atlantis.md)、共通仕様は[海・Underwater・Amphibious攻略](../systems/underwater.md)です。

### 一番単純な一般兵の入口

一般兵の役割とResource経済を明確に学びたいなら、まずMA Ulmが読みやすい基準です。

### SacredとPretenderを学ぶ

EA Abysiaは、Burning OneへのBlessと通常重歩兵のScalesを比較できます。

```text
Heavy BlessでSacred一体を強くする
vs
Scalesで全Fort・全Mageを強くする
```

交換条件をTestする教材です。

### Giantを学ぶ

EA Niefelheimは、高HP・高Damageの長所だけでなく、Shock、Fatigue、MR attack、Size、補充費を学べます。

### Communionを学ぶ

MA Pythiumでは、単にSlave数を増やすのではなく、

```text
必要Spell
→ 必要Path
→ 最小Slave数
→ Master数
→ Slave保護
```

の順に設計します。

### Undead・Popkillを学ぶ

MA Ermorでは、Populationと通常Recruitを失う代わりに、Dominion、Freespawn、Priest turn、Death Gemで国家を動かします。

```text
Gold economy
→ Temple・Lab・Fort・Mercenary

Death Gem economy
→ Priest・Mage・Commander・Summon
```

という資源変換を学ぶ教材です。

### Blood economyを学ぶ

EA Mictlanでは、Blood Slaveだけでなく、Hunter turn、Population、Unrest、Patrol、輸送、Templeを一つのNetworkとして管理します。

```text
Blood Hunt
→ Slave集約
→ Blood Sacrifice / Ritual / Sabbath
```

までつながって初めて国家Engineになります。

### UnderwaterとLandfallを学ぶ

MA Atlantisでは、海中で勝つこととGameに勝つことを分けます。

```text
海中Expansion
→ Coast確保
→ Landfall
→ 陸上Fort・Mage・Retreat route
```

を一つの作戦として設計します。

### Glamour・Stealth・Sailingを学ぶ

EA Vanheimでは、見えないArmyを増やすこと自体ではなく、正面Armyで敵を固定し、Stealth RaiderとSailingで守備先を増やします。

```text
Scout
→ 潜入
→ Raid / Assassination
→ 敵Reserveを移動
→ Main ArmyがFortを取る
```

高DefenceはAoE・Fatigue・True Sightへ崩れるため、通常兵・Item・Air・Bloodへ切り替える第二案も学びます。

### Flying・Stormを学ぶ

MA Caelumでは、Flyingを移動距離ではなく局地的集中として扱います。Stormは敵Flying・Archerを止める一方、自軍Flying・射撃も壊し得ます。

```text
No Storm plan
vs
Storm plan
```

を敵ごとに切り替える教材です。

### ResearchからStrategic Magicへ進む

LA Bogarusでは、早いResearchをFirst warへ使った後、Summon Mage、Global、Remote attackへPivotします。

```text
Research
→ Caster
→ Booster
→ Gem budget
→ Ritual
→ 次のAccess
```

まで接続し、研究量だけが高い国家で終わらないことを学びます。

### Stealthと多様な兵を学ぶ

EA Ulmは、正面ArmyとStealth Armyを使い分ける練習に向きます。国家兵は強い一方、射撃とMR攻撃への対策が必要です。

### Combined Armsと国家運営を学ぶ

LA Manは選択肢が多く、最初から簡単ではありません。しかし、射撃・前衛・Knight・Researcher・Fortを一つの国家エンジンとして組む練習になります。

> **「初心者向け」と「学習価値が高い」は同じ意味ではありません。**

操作や判断が多い国家でも、記事とTest gameを使えば特定テーマの教材になります。

## 初心者向け度は一つの数字ではない

「初心者向け」は、次の複数軸で分けるべきです。

- Expansionの許容幅
- Pretender設計の難しさ
- Researchルートの明快さ
- Battle Scriptの複雑さ
- Economyの特殊性
- Counterを受けた後の切替手段
- 操作量
- 一体または一Mageを失った損失
- 国家Site・Capital依存

ある国家がSingle Playerでは扱いやすくても、Multiplayerでは研究Timingや外交が難しい場合があります。

## 国家を選ぶ比較表

候補を二～三国に絞ったら、次を同じ形式で比較します。

```text
Nation / Age：
Expansionの主力：
Screen：
Damage source：
Recruit-anywhere Mage：
Capital-only依存：
Sacred供給：
Communion / Blood / Stealth等の特殊Engine：
第一Research Breakpoint：
第二Fortの価値：
Pretenderが補うもの：
最も危険なCounter：
一体の損失Cost：
毎Turnの操作量：
```

国家名やTierだけで決めず、最初の12TurnとFirst warを想像します。

## 最初のゲームでの目標

勝敗だけでなく、次のどれかを学べれば成功です。

- 二つ以上のExpansion Armyを作る
- Fortを増やしMageを継続雇用する
- Research Breakpointを一つ決める
- Battle Scriptを役割別に分ける
- Battle Replayから敗因を特定する
- 敵のProtection / MR / Resistanceに合わせてCounterを変える
- Giant・Sacred・Communionの交換条件を一つ説明できる
- Popkill・Blood・Underwaterのどの資源が通常国家と違うか説明できる
- Glamour・Flying・Strategic Ritualで、情報・Timing・Accessのどれを買っているか説明できる

国家を決めたら、[国家ページの読み方](how-to-read.md)を使ってRosterとMagic Accessを確認してください。その後、[Pretender設計サンプル](../pretender/samples.md)から国家の不足に近い設計骨格を二つ選び、同じ条件のTest gameで比較します。
