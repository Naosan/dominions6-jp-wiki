# 国家選択ガイド

最初の国家は「最強」より、**自分が何を学びたいか、どの操作量を許容できるか**で選ぶと理解が進みます。

## 最初に決める七つの質問

### 1. 一般兵を中心に戦いたいか

Yesなら、装備が明快で、Recruit-anywhere兵が主力になる国家が扱いやすいです。

確認するもの:

- Shield / Protection
- Weapon Damage
- Resource cost
- Formation Fighter
- MageによるArmy Buff

### 2. SacredとBlessを中心にしたいか

Sacred国家ではPretender設計が軍事力に直結します。

確認するもの:

- Cap-onlyかRecruit-anywhereか
- SacredのGold / Resource cost
- Priest供給
- Incarnate Bless依存
- Anti-Sacred兵への耐性
- 中盤以降の補充速度

Light Bless、Heavy Bless、Scalesとの交換、Incarnate Blessの登場時期は[Pretender設計サンプル](../pretender/samples.md)で比較できます。

### 3. GiantやMonsterを使いたいか

少数精鋭は一体ごとの性能が高い一方、包囲、Fatigue、MR攻撃、Armor Negating、Afflictionへの弱点があります。

確認するもの:

- HPとSize
- Defence
- Encumbrance
- Magic Resistance
- Regeneration access
- Chaffを用意できるか

### 4. Mage中心の戦闘をしたいか

Mage国家では、Pathの高さだけでなく**Recruit-anywhere Mageの価格とCommander Point**が重要です。

学びやすいテーマ:

- Army Buff
- Evocation
- Communion
- Skeleton spam
- Foul Vapors
- Battlefield Enchantment
- Magic Phase movement

### 5. Bloodを管理したいか

Bloodは独立した経済圏です。強い一方、Blood Hunter、Unrest、Population、Slave輸送を毎Turn管理します。

最初の一戦でゲーム全体を学びたい場合、Blood依存が低い国家の方が操作は軽くなります。

### 6. Stealth・Raid・機動戦をしたいか

正面決戦よりMap全体を動かしたいなら、次を重視します。

- Stealthy / Glamour
- Flying
- Sailing
- 高Map Move
- Cheap commander
- Magic Phase movement
- Province Defenceを抜く小部隊

### 7. Underwater国家を選ぶか

Underwater国家は地上侵攻、Amphibious性能、装備制限、海陸両方のFort生産を学ぶ必要があります。独自性は高いですが、最初のゲームでは陸上国家より判断項目が増えます。

## プレイスタイル別の国家類型

| 類型 | 主に学べること | 主な落とし穴 |
|---|---|---|
| 重歩兵・Earth | Protection、盾、Army Buff、Resource経済 | AN・毒・MR攻撃 |
| Archer / Fire | 射線、Friendly Fire、射撃強化 | Fire Resistance、Storm |
| Giant | 高HP、高Damage、少数精鋭 | Fatigue、包囲、即死 |
| Sacred rush | Pretender、Bless、Expansion Timing | 補充、Anti-Sacred |
| Communion | Mage量産、Script、Path boost | Slave過労死 |
| Undead | Reanimation、Darkness、消耗戦 | Priest、Holy damage |
| Nature持久戦 | Regeneration、Poison、Relief | Burst、Poison Resistance |
| Glamour / Stealth | 情報戦、Raid、Illusion | True Sight、Mindless |
| Blood | Blood economy、Demon、Sabbath | Micro、Unrest、人口 |
| Underwater | 海陸移行、Amphibious、独自Recruit | 地上展開の遅れ |

## 現在の学習用基準記事

国家の難易度を一つの数字で決めず、何を学びたいかで次の三記事を使い分けます。

| 国家 | 向いている学習テーマ | 最初に注意すること |
|---|---|---|
| [EA Ulm](ea/ulm.md) | 強い一般兵、複数攻撃、Shield役、Stealth Raid、Forge Bonus | 盾なし主力の射撃被害、低めのMR、Random Mage |
| [MA Ulm](ma/ulm.md) | Blacksteel、Resource経済、Earth Buff、重装Army、鍛造 | AP・AN・Poison、遅い部隊、Magic diversity |
| [LA Man](la/man.md) | Longbow・Crossbow、Friendly Fire、Drain研究、Mason、Fort network | 兵種選択の多さ、Mage個体差、Nature・Water不足 |

### 一番単純な入口を求める場合

一般兵の役割とResource経済を明確に学びたいなら、まずMA Ulmが読みやすい基準です。

### Stealthと多様な兵を学びたい場合

EA Ulmは、正面ArmyとStealth Armyを使い分ける練習に向きます。国家兵は強い一方、射撃とMR攻撃への対策が必要です。

### Combined Armsと国家運営を学びたい場合

LA Manは選択肢が多く、最初から簡単ではありません。しかし、射撃・前衛・Knight・Researcher・Fortを一つの国家エンジンとして組む練習になります。

> **「初心者向け」と「学習価値が高い」は同じ意味ではありません。**

操作や判断が多い国家でも、記事とTest gameを使えば特定テーマの教材になります。

## 初心者向け度は一つの数字ではない

「初心者向け」は、次の複数軸で分けるべきです。

- Expansionの許容幅
- Pretender設計の難しさ
- Researchルートの明快さ
- Battle Scriptの複雑さ
- Economyの特殊性
- Counterを受けた後の切替手段
- 操作量

ある国家がSingle Playerでは扱いやすくても、Multiplayerでは研究Timingや外交が難しい場合があります。

## 国家を選ぶ比較表

候補を二～三国に絞ったら、次を同じ形式で比較します。


国家名やTierだけで決めず、最初の12TurnとFirst warを想像します。

## 最初のゲームでの目標

勝敗だけでなく、次のどれかを学べれば成功です。

- 二つ以上のExpansion Armyを作る
- Fortを増やしMageを継続雇用する
- Research Breakpointを一つ決める
- Battle Scriptを役割別に分ける
- Battle Replayから敗因を特定する
- 敵のProtection / MR / Resistanceに合わせてCounterを変える

国家を決めたら、[国家ページの読み方](how-to-read.md)を使ってRosterとMagic Accessを確認してください。その後、[Pretender設計サンプル](../pretender/samples.md)から国家の不足に近い設計骨格を二つ選び、同じ条件のTest gameで比較します。
