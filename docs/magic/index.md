# 魔法の基本

Dominions 6 の魔法は、基本的に次の三つを組み合わせて考えます。

> **Research × MageのMagic Path × Gem / Blood Slave**

研究しただけでは、要求Pathを持つMageがいなければ使えません。

## PathとSchoolは別物

FireだからEvocationだけ、EarthだからAlterationだけ、というわけではありません。

同じPathの重要Spellが複数のResearch Schoolに分散しているため、国家ごとに「どのResearch Breakpointを最初の戦争に間に合わせるか」を考えます。
