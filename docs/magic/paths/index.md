# Magic Path 総論

各Pathを「何の属性か」ではなく、**何を勝利条件に変換できるか**で覚えます。

| Path | 得意分野 | 覚え方 |
|---|---|---|
| Fire | 範囲火力・熱・射撃強化 | 敵軍を早く減らす |
| Air | Shock・機動・射撃対策 | 鎧を無視し、戦場を選ぶ |
| Water | Quickness・Cold・Fatigue | 戦闘テンポを変える |
| Earth | Protection・Strength・拘束 | 普通の兵を強化する |
| Astral | Communion・MR攻撃・転移 | Mageの数を高Pathへ変換する |
| Death | Undead・Darkness・消耗 | Gold以外から軍を作る |
| Nature | Regeneration・Poison・回復 | Living Armyを持久戦向けにする |
| Glamour | Luck・Illusion・Confusion | 敵の行動と判断を壊す |
| Blood | Blood Hunt・Demon・Sabbath | Populationを別の魔法経済へ変える |
| Holy | Bless・Banishment | Sacredと対Undead/Demon |

詳細は各Pathページへ。
