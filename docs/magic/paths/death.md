# Death

**Deathは、Goldを使わずUndead Armyを作り、Skeletonで時間を稼ぎ、Darkness・Fatigue・Disease・Life Drainで消耗戦を支配するPathです。**

敵を一撃で消すだけでなく、MageとGemを繰り返し使える軍・Commander・不死化へ変換します。

---

# Deathの勝ち筋

## Skeleton spam

D2前後のMageを複数並べ、戦闘中にSkeletonを生成し続けます。

Skeletonの役割：

- Enemy Chargeを消費
- 攻撃回数を吸収
- Mageを守る
- 敵を疲れさせる
- Battlefield spell完成まで時間を稼ぐ
- 高価な兵の損失をUndeadへ置き換える

Skeleton一体の強さではなく、**毎Round補充される前線**として評価します。

## Darkness

Darkvisionの低い敵ArmyのAttack・Defence・Precisionを下げ、自軍Undead・Demon・Darkvision兵だけを有利にします。

## Rigor / Fatigue

生者を継続的に疲労させ、気絶した後にUndead・Life Drain・通常兵で処理します。

## Life DrainとSoul Vortex

Thug / Supercombatantが敵からHPとFatigueを吸収し、長時間戦います。

## Disease・Decay・Affliction

即座に倒さなくても、敵Commander・Giant・Pretenderを長期的に弱体化します。

## Undead / Mage召喚

Death Gemを、

- Chaff
- Elite Undead
- Raider
- Thug chassis
- Death Mage
- Lich
- Tartarian級戦力

へ変換します。

# Path level別の役割

| Path | 主な役割 |
|---:|---|
| D1 | Anti-undead、Decay / Affliction、低級召喚、Forge |
| D2 | Raise Skeletons / Horde系、実戦Mageの基準 |
| D3 | Soul Vortex、Shadow / Drain、Thug支援 |
| D4 | Darkness、Rigor級、Army-wide消耗戦 |
| D5～6 | Lich、Wraith、強力なMage・Army召喚、Global |
| D7以上 | Tartarian級・世界規模Ritual・終盤召喚 |

Deathでは、**多数のD2**が特に重要です。

高Path一人の大Spellより、D2 Mage十人が毎RoundSkeletonを増やす方が、敵Armyの攻撃を長く吸収する場合があります。

# 重要Spellの見方

## Raise Skeletons / Horde of Skeletons

D2 Mageを「一人分の兵士」ではなく、毎RoundのUnit生成装置へ変えます。

### 強い相手

- 攻撃回数の少ない高Damage兵
- Lance cavalry
- Fatigueする生者
- 単体Thug
- Mageが後ろにいるArmy

### 弱い相手

- Banishment
- 大AoE Fire / Holy
- Trample
- Cleave / Sweep / multiple attack
- Undead control
- Darknessに適応した敵

Skeletonだけで勝つのではなく、敵を拘束して別の勝利Spellを通します。

## Darkness

自軍のDarkvisionを確認してから使います。

Undeadだから常にDarkness無効とは限らず、UnitごとのDarkvision値を見ます。

敵もUndead、Demon、Cave適応、Darkvisionなら優位が小さくなります。

## Rigor Mortis

戦場全体のFatigueを増やす代表Spellです。

自軍がUndead / Lifeless / Reinvigoration / Relief等で耐え、敵生者だけを気絶させます。

Casterが死ぬと解除される効果かを確認し、Bodyguardを付けます。

## Soul Vortex

Caster周囲から生命力を吸収し、Thugを長期戦向けにします。

Chaffに囲まれるほど回復源が増える一方、

- Lifeless
- Undead
- 高Damage Burst
- MR / Soul attack
- Fatigue対策

を確認します。

## Twiceborn

Mage死亡時に別のUndead形態で戻す保険です。

高価なDeath Mage、Battle Mage、Affliction持ちMageを再利用できますが、戻る場所・形態・能力変化を確認します。

## Lichcraft系

Mageを不死・Undeadへ変換し、老齢・Disease・Upkeep・死亡Riskを変えます。

Holy CounterとUndead Leadershipが新たな弱点になります。

## Tartarian Gate級

非常に強力なCommander / Monsterを得ますが、Affliction、Feeblemind、Leadership、Gift of Reason系の追加投資が必要になる場合があります。

一体のStatsだけでなく、**正常に使える割合と修復Cost**を含めて評価します。

# 戦場での使い方

## Skeleton screen

```text
前方：少数Chaff
後方：D2 Mage群
側面：通常主力 / Raider
高Path Mage：Darkness / Rigor / Damage
```

D2 MageがSkeletonを作り、敵が疲れた後に主力を当てます。

## Darkness Army

```text
自軍：Darkvision / Undead / Demon
敵固定：Skeleton
Battlefield：Darkness
Damage：Shadow / Magic weapon / 通常兵
```

自軍のPrecisionも含めてDarkvisionを確認します。

## Anti-Thug

- Life Drain
- Soul attack
- Decay
- Curse
- Fatigue
- Skeletonによる包囲
- Control Undead（対象がUndeadなら）

一つの即死Spellだけでなく、相手のRegen・MR・Undead分類に合わせます。

# Ritual・召喚・経済

## Death Gemの価値

Death Gemは、低級Skeleton Armyから高級Mage・Lich・Tartarianまで用途が広く、常に不足しやすい資源です。

- 目前の戦争
- Booster
- Mage召喚
- Long-term summon
- Global / Remote ritual

へ予算を分けます。

## Corpseの利用

Provinceや戦場の死体数を使う召喚・Ritualがあります。大戦後のProvinceが資源になります。

## Remote ritual

Disease、Assassination、Army damage、Undead uprising等で、敵後方を直接攻撃します。

Dome、Astral protection、報復Ritualを確認します。

## Undead Leadership

召喚したUndeadを率いるにはUndead Leadershipが必要です。Mageを召喚してもArmy Commanderが不足する場合があります。

# 相性のよいPath

## Nature

Regeneration、Poison、Disease、Life Drain、Reliefを組み合わせます。生者と死者の両方を扱う消耗戦です。

## Astral

Communion、Soul attack、Teleport、Antimagic。ProtectionとMRの二層へ圧力をかけます。

## Earth

Skeletonで時間を稼ぎ、Earth Army buffと拘束を完成させます。ReinvigorationはDeath Mageにも有用です。

## Fire

Skeletonが敵を密集させ、Fire AoEで処理します。ただし自軍UndeadもFireへ弱い場合があります。

## Glamour

IllusionとSkeletonの両方で敵攻撃を浪費させ、Darkness・Confusionで行動を崩します。

## Blood

Demon、Death crosspath、Sabbath、Soul / Disease Ritualへつながります。

---

# Counter / 弱点

## Priest / Banishment

Undead Armyへの専用Counterです。

- Priestを射撃・Rear attackで狙う
- DarknessでPrecisionを落とす
- 生者兵を混ぜる
- Anti-priest spellを使う

等で対策します。

## Fire / Holy AoE

大量Skeletonを一度に消します。Fire Resistance、散開、敵Caster排除を考えます。

## Undead Control

敵がControl Undead系を持つと、高価なUndeadまで奪われる可能性があります。MR、Antimagic、Caster狩りを用意します。

## Magic Leadership

Undead CommanderやLeadershipを失うとArmyが機能しません。Commanderを分散します。

## Darkness適応

敵もDarkvisionを持つ場合、研究投資とGemが優位を作りません。

## 長期投資

高級召喚へGemを貯めすぎると、中盤Armyが不足します。

## Holy classification

Lich化・Undead化によって、Poisonや老齢へ強くなる代わりにHoly Counterを受けます。

---

# Deathを選ぶ判断

- D2 Mageを何人雇えるか
- Skeletonを処理するPriest / AoEが敵にいるか
- 自軍はDarknessへ適応しているか
- Death Gemを中盤と高級召喚へどう分けるか
- Undead Leadershipは足りるか
- EnemyがUndeadならControl / Anti-undeadを使えるか
- Battle Mageを前線へ出した研究損失を補えるか
