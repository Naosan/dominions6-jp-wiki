# Glamour

**GlamourはDominions 6で追加された、Illusion・Dream・Luck・Confusion・欺瞞を扱うSorcery Pathです。**

敵を直接焼くより、

- 攻撃対象を増やす
- 本物へ命中しにくくする
- 行動を混乱させる
- Moraleを崩す
- 戦力情報を隠す
- 夢・Stealth・Magic Phaseから攻撃する

ことで戦闘と戦略判断を壊します。

Dom5以前のIllusionがAir等に置かれていた攻略情報は、そのまま適用できません。

---

# Glamourの勝ち筋

## Luck

致命的な攻撃を確率的に無効化する防御層を作ります。

Protection、Defence、Regenerationとは別の層なので、高価なSacred、Thug、Mageへ重ねると効果的です。

## Illusion

False Horror、Phantasm、Mirror Image、Mirage等で、敵の攻撃回数を本物ではない対象へ浪費させます。

Illusion一体のDamageではなく、**敵が本物を攻撃できない時間**が価値です。

## Confusion

敵Unitの行動を不安定にし、

- その場で無駄行動
- 不適切な移動
- 陣形崩壊
- 後衛への迷走
- 命令無視

を引き起こします。

## Fear・False threat

False Horror等でMoraleへ圧力をかけ、HPを削り切る前にRoutさせます。

## Stealth・Glamoured Army

Enemy偵察へ正確なArmy情報を与えず、戦力・移動先・編成を誤認させます。

## Dream / Remote action

夢を通じた暗殺、偵察、移動、Provinceへの干渉等で、通常戦闘前にCommanderへ圧力をかけます。

---

# Path level別の役割

| Path | 主な役割 |
|---:|---|
| G1 | Personal Luck、低級Illusion、Stealth / Forge補助 |
| G2 | Group Luck、Confusion、実用Support Mage |
| G3 | False Horror、広範囲Confusion、Battle Mage |
| G4～5 | Mirage、Mass effect、Mists of Deception級の戦場支配 |
| G6以上 | Dream / Global / Fata Morgana級、終盤情報戦 |

GlamourはG2～3でも仕事が多く、

> **G2～3支援を複数＋G4～5のBattlefield担当**

が扱いやすい構成です。

# Researchの方向

## Alteration

- Personal / Group Luck
- Displacement
- Mirror / Illusion defence
- Invisibility / concealment
- Body・appearanceの変化

高価な少数Unitを守ります。

## Thaumaturgy

- Confusion
- Charm / Entrancement
- Dream attack
- Mind effect
- Scrying / deception

MRとMindless classificationを攻撃します。

## Conjuration

- False Horror
- Phantasmal Warrior / Army
- Dream creature
- Glamour Mage召喚

敵Attackを吸収する一時UnitとMagic diversityを得ます。

## Enchantment

- Mists of Deception
- Army-wide illusion / luck
- Battlefield concealment
- Fata Morgana等のGlobal

戦場・Province・世界の情報を変えます。

## Evocation

Glamour Damage、Phantasmal attack、Mind / illusion projectile等があります。実体Damageか、MR判定か、Illusion効果かを確認します。

## Construction

- Glamour Booster
- Luck / Displacement Item
- Stealth / Invisibility Item
- Dream / Mirror equipment
- Thug向け防御

Dom6新Pathなので、古いItem表ではAir Itemとして掲載されている場合があります。現行データを優先します。

# 重要Spellの見方

## Personal Luck / Group Luck

確率防御を個人または集団へ配ります。

### 向くUnit

- 高価
- 高HP / 高Protectionで、一回の無効化が生存時間を伸ばす
- Regeneration持ち
- Thug / Sacred / Mage

### 弱点

- 多段攻撃で試行回数を増やされる
- Luckを無視・除去する効果
- 持続Damage
- Fatigue / Morale / Control

LuckだけでArmyを守るのではなく、別防御と重ねます。

## False Horror

一時的な恐怖・幻影Unitを作り、敵の攻撃とMoraleを乱します。

高Morale、Mindless、True Sight等の敵には効率が落ちる場合があります。

## Confusion / Mass Confusion

敵Armyの行動効率を下げます。

特に、

- Formation依存Army
- 高価な少数精鋭
- Mage群
- Rear attack部隊

へ成功すると、役割分担を崩せます。

Mindless、高MR、Antimagicへは別攻撃を用意します。

## Mirage

戦場の視認・距離・命中・Illusion環境へ影響する大規模Spellです。

自軍のPrecision、True Sight、Darkvision、Illusion適性も確認します。

## Mists of Deception

戦場へ継続的にIllusion / Phantasmを供給し、敵攻撃を浪費させる勝利Spellです。

Caster生存と戦闘時間が重要です。Casterを倒されると効果が止まる可能性を確認します。

## Fata Morgana

Province defence、Illusion、偵察情報等へ影響するGlobalです。

直接Incomeだけでなく、Enemyが各Provinceへ必要とするRaid戦力を増やすことで間接的価値を生みます。

# 戦場での使い方

## Luck精鋭

```text
前衛：Chaff / Illusionで最初の攻撃を吸収
Glamour Mage：Luck / Displacement
精鋭：Hold and Attack
Support：Regeneration / Protection / Antimagic
```

高価な精鋭を最初から接敵させず、Buff完成後に投入します。

## Confusion Army

```text
敵固定：盾兵 / Skeleton / Illusion
Glamour Mage群：Confusion
Damage：Fire / Air / 通常兵
```

Confusionは敵を倒すのではなく、別火力が処理できる状態へします。

## Mists / Illusion長期戦

```text
Caster：Battlefield illusion
前衛：耐久兵
Support：Relief / Regeneration
後衛：射撃 / MR attack
```

敵が幻影を処理している間に、別のDamage・Fatigueを蓄積します。

---

# 戦略マップでの使い方

## Glamoured Army

Armyの正確なUnit構成や人数を偵察から隠します。

目的：

- Enemyに過剰防衛を強いる
- 本隊と囮を区別させない
- Sacred / Mageの存在を隠す
- Counter研究を遅らせる

## Stealth Raid

Glamour UnitはStealth、Forest / Dream movement、Assassin等と組み合わさる場合があります。

正面決戦より、

- 後方Province
- Lab
- Temple
- Retreat route
- Fort construction

を狙います。

## Dream attack

Enemy Commanderの睡眠・夢へ干渉するRitualがあります。

対象のMR、Mindless、Dome、Province条件を確認します。

## Scryingと偽情報

自分の情報を隠しつつ、Enemy ArmyをScryし、非対称な情報優位を作ります。

# Ritual・召喚・経済

## Site Search

Glamour SiteはDom6固有です。Glamour Gem income、Glamour Mage、Illusion recruitment、Luck / Dream / Stealth効果を持つ場合があります。

## Glamour Summon

- Illusion troop
- Dream creature
- Stealthy Raider
- Glamour Mage
- Luck / Fear / Confusion unit

を得ます。

Illusion Unitは低Upkeep・一時性・Magic weaponへの弱さ等、通常Unitと異なる性質を確認します。

## Global / Province effect

Fata Morgana等、Enemyの偵察・Raid計算・Province defenceを歪める効果があります。

数字として見えにくい一方、Enemyの行動Costを増やします。

# 相性のよいPath

## Air

Flight、Mist、射撃防御、Glamourで高価な軽装精鋭を守ります。奇襲とMagic Phase移動も強化します。

## Astral

Communion、MR attack、Antimagic、Teleport。高MRに止められやすい共通弱点があるため通常Damageも用意します。

## Nature

Luck＋Regenerationで複数防御層を作り、Reliefで長期戦を維持します。

## Earth

Illusionで攻撃を散らし、本体へProtection・Strengthを配ります。

## Death

SkeletonとIllusionで敵攻撃を大量に浪費させ、Darkness・Confusion・FearでMoraleを崩します。

## Blood

Dream / Fear / Demon / Sabbathから高級Glamour・MR攻撃へ進みます。

---

# Counter / 弱点

## Mindless

Confusion、Charm、Fear等の精神効果へ強いCounterです。

## 高MR・Antimagic

MR Negates系Glamour Spellを止めます。通常Damage、Poison、Physical buffを混ぜます。

## True Sight / Spirit Sight / Disbelieve

Illusion、Glamour、Invisibilityへの明確な対策です。Enemy CommanderとBlessを確認します。

## Magic Weapon

Phantasmal / Ethereal Unitへ有効な場合があります。Illusionの個別性質を確認します。

## 多段攻撃

Luck、Mirror Image、Displacement等へ多くの試行回数を作ります。

## AoE

本物とIllusionをまとめて攻撃し、Mirror / Imageを剥がします。

## 不安定性

確率防御・Confusion・Moraleに依存するため、同じ戦闘でも結果が振れます。重要戦では第二の安定したDamage源を用意します。

## Caster依存

Mists等の大SpellCasterを暗殺・Rear attackで失うとArmyが機能しません。

---

# Glamourを選ぶ判断

- 高価な少数UnitへLuckを重ねる価値があるか
- 敵はMindless / 高MRか
- True Sightを持つCommanderがいるか
- Illusionが稼いだ時間で何が敵を倒すか
- G2～3 Mageを何人並べられるか
- 情報優位をRaid・外交へ変換できるか
- 確率戦術が失敗した場合の第二案があるか
